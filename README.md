# 📚 Online Library Management System

A web-based application to manage library books, tracking issues and returns. Built with the PERN-lite stack (MySQL, Express, Node.js).

 🚀 Features
  View Books: Real-time list of available and issued books.
  Issue System: Assign books to students with a simple prompt.
  Return System: Update book status back to "available" with one click.
  Responsive UI: Clean grid layout for easy navigation.

 🛠️ Tech Stack
  Frontend: HTML5, CSS3, JavaScript (ES6+)
  Backend: Node.js, Express.js
  Database: MySQL
